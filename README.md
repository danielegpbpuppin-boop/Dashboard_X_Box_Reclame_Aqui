##  Sobre o Projeto

Este projeto consiste na criação de um **Dashboard Interativo de Vendas no Microsoft Excel**, desenvolvido com foco na organização, tratamento e visualização de dados de assinaturas do **Xbox Game Pass** e seus pacotes adicionais (*Season Passes*).

O objetivo principal é transformar dados brutos de vendas em informações visuais claras e estratégicas, facilitando o acompanhamento de receitas, o comportamento de renovação dos assinantes e a tomada de decisões baseadas em dados.
